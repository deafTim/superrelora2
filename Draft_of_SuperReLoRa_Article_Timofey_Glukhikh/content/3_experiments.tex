\paragraph{Goal.}
We evaluate whether enforcing column-space orthogonality at merge-and-reinit improves over standard LoRA and over ReLoRA when the training budget is matched.
The only algorithmic difference between ReLoRA and SuperReLoRa is the orthogonal projection of $W_A$ at reinitialization~\eqref{eq:orth}; LoRA uses the same adapter parameterization but never merges.

\paragraph{Setup.}
All methods fine-tune \texttt{nicholasKluge/TeenyTinyLlama-160m} on WikiText-2~\cite{merity2016pointer} (train split for training, validation for evaluation).
Unless stated otherwise we use rank $r{=}8$, LoRA scaling $\alpha_{\mathrm{LoRA}}{=}16$, learning rate $2{\times}10^{-4}$, batch size $8$, sequence length $512$, and three epochs.
Adapters are attached to attention and MLP projections
(\texttt{q/k/v/o\_proj}, \texttt{gate/up/down\_proj}).
For ReLoRA and SuperReLoRa we merge every $q{=}500$ steps, prune $99\%$ of low-magnitude Adam moments, and apply a short jagged learning-rate warmup after each merge.
LoRA uses the same optimizer and schedule without merge-and-reinit.
Experiments run on the Zhores HPC cluster (SLURM partition \texttt{gpu\_devel}, single GPU).

\paragraph{Methods.}
\begin{itemize}
    \item \textbf{LoRA:} frozen base weights, single low-rank adapter, no merge.
    \item \textbf{ReLoRA:} periodic full merge into $W$, random reinit of $W_A,W_B$, Adam prune, jagged LR warmup.
    \item \textbf{SuperReLoRa:} same as ReLoRA, plus column-space orthogonalization of $W_A$ against the accumulated basis $U$ at each reinit.
\end{itemize}

\paragraph{Metrics.}
We report training loss, validation perplexity, and token-level next-token accuracy.
To probe the intended mechanism we also track (i)~the residual overlap $\|W_A^\top U\|_F$ immediately after reinit and (ii)~the dimension of the accumulated basis $U$ (or an effective-rank estimate of the summed update $\Delta W$) as a function of the number of cycles.
